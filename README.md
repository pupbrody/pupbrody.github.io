# pupbrody.github.io

정재성 교대근무표를 달력으로 조회하는 정적 페이지입니다.

- 공개 주소: https://pupbrody.github.io
- 저장소: pupbrody/pupbrody.github.io (공개, 기본 브랜치 main)

## 스타일

다크모드 스타일입니다. 배경은 어두운 회색, 카드도 어두운 회색, 글자는 밝은 회색이며, 날짜색은 다크모드에 맞게 평일 밝은 회색·토요일 밝은 파랑·일요일 밝은 빨강으로 표시됩니다.

## 모바일

모바일에서는 달력 칸 높이가 112px, 출·퇴근 시간 글자가 9px로, 날짜·라벨·출근·퇴근 시간(야간 퇴근도 시간만 표시)이 칸 안에서 잘리지 않고 표시됩니다.

달력 칸에는 출근시간 윗줄에 근무번호(DIA)가 표시됩니다. 예: 11/4 야간 칸에 15dia, 출 19:37, 퇴 09:36. PC 칸 높이는 102px입니다.

## 보는 방법

년 > 월 > 날짜 순서로 선택하면, 그 날짜의 근무가 표시됩니다.

- 주간 / 야간 여부
- 출근시간, 퇴근시간 (야간 퇴근도 시간만 표시)
- 휴가 여부: 지휴, 연차, 연지, 분지
- 비번·휴가 날은 어두운 노란색 dim 배경으로 표시 (휴가인 날과, 해당 월 데이터가 있는데 근무가 없는 날)
- 날짜 칸 높이는 모두 동일, 날짜 색은 다크모드에 맞게 평일 밝은 회색·토요일 밝은 파랑·일요일 밝은 빨강, 오늘 날짜는 빨간색 테두리
- 라벨 색: 주간 회색 배경, 야간 파란색 배경, 휴가 빨간색 배경
- 날짜를 클릭하면 그 날짜의 근무 정보 아래에 그날에 맞는 행로표 이미지가 표시된다 (예: 11/1 휴일주간 9번, 11/4 평일야간 15번). 비번·휴가인 날은 행로표가 없다.
- 사용자가 근무표를 업데이트할 때마다 이 페이지도 같이 수정한다.

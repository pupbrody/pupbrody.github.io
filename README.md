# pupbrody.github.io

정재성 교대근무표를 달력으로 조회하는 정적 페이지입니다.

- 공개 주소: https://pupbrody.github.io
- 저장소: pupbrody/pupbrody.github.io (공개, 기본 브랜치 main)

## 보는 방법

년 > 월 > 날짜 순서로 선택하면, 그 날짜의 근무가 표시됩니다.

- 주간 / 야간 여부
- 출근시간, 퇴근시간 (야간은 익일 퇴근시간으로 표시)
- 휴가 여부: 지휴, 연차, 연지, 분지
- 쉬는 날은 노란색 dim 배경으로 표시 (휴가인 날과, 해당 월 데이터가 있는데 근무가 없는 날)
- 날짜를 클릭하면 그 날짜의 근무 정보 아래에 사용자가 준 원본 근무표 이미지도 함께 표시 (현재는 2026년 11월 근무표 사진)

## 데이터

- 현재 데이터: 2026년 11월 근무표 (사용자가 준 근무표 사진과 iPhone 미리알림 대조로 검증된 내용)
- 2026년 11월: 근무 16건, 지휴 2건(11/6, 11/20), 연차 1건(11/2)

## 업데이트 방법

새 근무표 사진을 Muse에게 주면, Muse가 이 저장소의 `schedule.json`과 달력 데이터를 업데이트하고 GitHub Pages에 다시 게시합니다.
